# 眠序 · 智能床垫算法与可视化

基于智能床垫压力采集数据实现睡姿分类、身体区域预测、用户识别与可视化，已完成一次全量训练。GitHub 发布内容为 `src/`、`tests/`、`README.md` 和 `requirements.txt`；原始数据、任务文档及训练产物不随代码发布。

## 启动

建议 Python 3.11 或更新版本。已在本工作空间的 Python 3.14、NumPy 2.4.6、scikit-learn 1.9.0 环境验证。

下载代码后，先按下方“数据组织”将另行获取的数据放入项目根目录的 `data/`，再执行：

```bash
python -m pip install -r requirements.txt
python -m src.train
python -m src.visual.app --port 8000
```

浏览器打开地址 [http://127.0.0.1:8000](http://127.0.0.1:8000)

首次使用需先训练以生成模型和评估结果；后续已有训练产物时可直接启动 Web 服务。跨 scikit-learn 版本使用时请重新训练。所有命令从项目根目录执行；服务默认仅绑定本机。

无需手动创建 `log/`、`output/` 或 `output/models/`：训练和 Web 服务启动时会自动创建缺失目录，已存在的目录可重复使用。自动创建目录不会下载数据或生成模型；删除训练产物后需重新训练。

训练约需 3–4 分钟，实际取决于 CPU。可设置 `OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4` 控制数值库并行度。前端为本地原生 JavaScript / CSS

## 页面与功能

- **实时监测**：切换动态采集文件，按文档 70 秒回放，播放/暂停/拖动时间轴；真实 44×24 压力矩阵、最大值、全矩阵均值、接触面指数、压力重心和身体状态；点选 68 个气囊，显示示例充气量/支撑高度、关联点压力及时间曲线。
- **睡姿图谱**：切换 SAI / dgs 组别，查看四类睡姿。使用提供的 PNG 页面，支持查看完整图及其帧号、色标；不将不存在的用户图片编造为已有资料。
- **身体区域**：选择任意采集用户、动作、帧号；比较五个预测框与准确匹配原始压力矩阵的人工标注；同时提供 hpy 的四类区域标注 PNG 参考。缺失标注时明确提示。
- **用户识别**：展示已注册/未注册用户匹配结果、模板距离和拒绝阈值；PCA 二维特征图可悬停查看；可用所选动作前五帧增量注册用户，无需改变模型结构。
- **算法评估**：真实模型对比、精确率、召回率、F1、混淆矩阵、区域指标、FAR/FRR、用户划分及 JSON 导出。

## 数据组织

`data/` 与 `src/` 同级，路径由 `src/config.py` 按项目位置确定。保留原始文件名、目录名和大小写，尤其是 `Spos_data`、`SAI` 和 `heapmap(Partial)`（沿用原数据拼写）。目录示例如下，省略号表示其他同类文件：

```text
data/
  readme                              成员身高、体重信息，仅供参考
  Spos_data/                          原始压力 TXT，按采集用户分目录
    SAI/
      SAI_1.txt                       静态动作 1
      ...
      SAI_21.txt                      静态动作 21
      SAI_空载.txt                    空载参考，不参与四类睡姿训练
    dgs/
      dgs_1.txt
      ...
      dgs_动态一.txt                  动态回放数据
    ...
  structure_data/
    data.json                         逐帧压力与身体区域标注
  heapmap(Partial)/                    已提供的 PNG 展示图
    睡姿原始数据部分热力图/
      origin_heatmap_page_001.png
      ...
    区域划分数据部分热力图/
      page_0001.png
      ...
```

- **静态 TXT**：程序读取 `Spos_data/<用户目录>/*_<动作编号>.txt`，动作编号为 1–21，用户身份以父目录名为准（例如 `lzx1/lzx_1.txt`）。每行有 24 个逗号分隔的非负压力值，连续 44 行组成一帧，文件内可有多帧；空行及单行 `0`、`1`、`2` 会被忽略。现有数据包含镜像帧，静态文件帧数须为偶数。
- **动态与空载 TXT**：文件名含“动态”的 TXT 用于回放，格式与静态压力矩阵相同；动态与空载文件均不参与静态训练。并非每位用户都有动态文件，不需补造。
- **区域 JSON**：顶层为记录数组，每条记录包含 `people`（用户编号）、`people_name`（用户目录名）、`action`（1–21）、`frame`（原帧号）、`sleep_pos`（0–3）、`data`、`region` 和 `spine`。`data` 是由 1,056 个逗号分隔读数组成的字符串，按行重排为 44×24；`region` 是 24 个空格分隔坐标，前 12 个依次为六个区域的左右边界，后 12 个依次为上下边界。区域顺序为肩、背、腰、臀、大腿、小腿；当前仅使用前五区，小腿可缺失，`spine` 不参与训练。
- **PNG 与成员信息**：PNG 仅用于图谱及标注参考，不参与训练；缺失图片不会加入图像目录。`data/readme` 的身高、体重信息不参与当前模型计算。

| 动作编号 | `sleep_pos` | 睡姿 |
| --- | --- | --- |
| 1–6 | 0 | 仰卧 |
| 7–9 | 1 | 俯卧 |
| 10–15 | 2 | 左侧卧 |
| 16–21 | 3 | 右侧卧 |

完整训练需要 `Spos_data/` 的静态数据和 `structure_data/data.json`；完整页面展示还需要动态 TXT 和上述 PNG。请使用配套完整数据集复现实测结果和运行集成测试。`doc/` 仅为开发参考资料，运行时无需提供。

本地 `.gitignore` 已排除 `data/`、`doc/`、`log/`、`output/` 和 Python 缓存。按上述发布范围暂存文件可执行 `git add src tests README.md requirements.txt`，其中 `src/visual/static/` 也必须一并上传。

## 数据与评估口径

1. 原始数据共 **33 人、23,760 帧**；结构化区域数据共 **30 人、21,570 帧**。实际每帧长度均为 **1,056，即 44×24**，采用实测格式，忽略文档旧版 40×26 描述。保留原始数据，不覆盖文件。
2. 动态 TXT 中的单行 0/1/2 按文档忽略，不作为监督标签使用；动态文件不进入静态训练。空载文件保留，不混入四类睡姿。压力指标保留原始读数，未擅自换算 kPa 或体重；未把没有标定的基线减除作为可信物理校准。
3. 已有镜像不重复增加。先划分，再仅对训练帧应用一次 0.9–1.1 倍增益、σ=1.5 读数噪声，零压力点保持为零。区域坐标不变。镜像对应帧通过用户、左右对应动作及原帧号组成家族，同一任务内不跨数据分区。
4. 睡姿按用户固定随机种子 42 划分 **23 人训练 / 10 人测试**（70%/30% 向上取整测试人数）。先在训练用户内部按用户验证选择算法，再训练全部训练用户，最后评估两个模型；最终测试用户不用于选择模型或超参数。
5. 区域任务先隔离新用户；剩余用户按镜像家族 70%/30% 划分训练/验证，区域验证和新用户测试使用同一个模型。只处理肩、背、腰、臀、大腿，忽略缺失的小腿和未要求的脊柱点。坐标按 `(x1,y1,x2,y2)` 零起点、右下边界不包含解释。
6. 原要求未指定区域“准确率”定义，本实现明确采用 **每个矩形 IoU≥0.5 的正确比例**，并报告平均 IoU、逐区域得分、五框同时正确率和坐标 MAE；不使用被背景主导的像素准确率。这个度量应在正式验收时与指导教师确认。
7. 用户识别按镜像家族约 60%/20%/20% 分为注册、阈值校准、测试；未知用户也分为互不相交的校准/测试两组。PCA 和标准化仅在注册数据拟合。以独立校准未知用户 FAR≤5% 为阈值选择条件；不人为增加误拒绝来凑目标区间。单次采集相邻帧相关性强，闭集高分不等同于跨夜/跨设备泛化。增量注册保存到独立的 `identity_enrolled.joblib`，不修改原始实验快照。
8. 侧卧名称严格遵循采集文档定义（例如数据中的“左侧卧”为右半身在下），不重新解释医学方位。

## 当前实测结果

| 任务 | 结果 | 文档要求 |
| --- | ---: | --- |
| 睡姿 RBF-SVM（内部验证选择的最优模型） | 98.42% | >95%，达到 |
| 睡姿 ExtraTrees（对比基线） | 92.69% | >95%，未达到 |
| 区域同用户验证，IoU≥0.5 | 99.91% | >95%，达到 |
| 区域新用户，IoU≥0.5 | 78.28% | >70%，达到 |
| 用户闭集识别 | 100.00% | >95%，达到 |
| FAR | 1.67% | 1–5%，达到 |
| FRR | 0.00% | 5–10%，低于指定区间 |

完整精确率、召回率、F1 和每个区域的 IoU 见 `output/metrics.json`。ExtraTrees 基线与 FRR 的字面区间未全部满足，不能将所有指标宣称为全部验收通过。FRR 为零表示本测试集未出现拒绝已知用户，并非识别错误。

## 展示数据来源与限制

- 图谱和区域参考图直接使用 `data/heapmap(Partial)` 文件。索引只标记人工读过的首图，原始整页可能混有多个动作；页面编号不是用户编号。
- 实时面板实际是动态数据回放。压力热力图、统计值及单点曲线来自真实 TXT 数值，未从 PNG 颜色反推精确压力。PNG 已经有插值且数据本身可用，使用原始矩阵更准确。
- 气囊编号按 `doc/pdf/气囊-传感器 标注 布置图20240624.pdf` 手工转录，双侧共 68 个（0–67）；图中网格与数据维度不完全一致，因此采用归一化示意映射。左侧关联一块 44×24 矩阵，右侧没有采集读数，显示为空。
- 只有**一组**有界的充气调节示例，可调强度。充气量和支撑高度不是实测，也不修改原始压力矩阵；不宣称证明真实调节因果效果。未连接气泵或硬件控制接口。
- 没有逐帧时间戳，按 70 秒等间隔显示。身体状态通过压力变化和模型姿态变化推断，阈值为启发式，未报告虚构的动态状态准确率。没有 EEG 或睡眠分期标签，不显示深睡/浅睡、医学结论或虚构睡眠评分。
- 已阅读本地参考论文 *Estimating pose from pressure data for smart beds with deep image-based pose estimators*，其任务是关键点姿态估计；本实现采用适用于现有四类睡姿及矩形标注的机器学习方法，不宣称复现该论文模型或借用其精度。

## 验证

```bash
python -m pytest -q -p no:cacheprovider
```

请先准备完整数据并完成训练，再运行上述测试；其中集成测试依赖配套数据、PNG 和训练产物。测试覆盖原始数据解析、镜像家族隔离、增强边界、区域 IoU、增量注册、气囊编号、接口输入边界、真实模型推断和动态帧变化。浏览器验收脚本为 `tests/browser_smoke.py`，需自行安装 Playwright 和 Chromium 并启动 Web 服务后运行；截图和验收结果存放在自动创建的 `output/`。

主要接口：`GET /api/catalog`、`GET /api/frame?person=SAI&action=1&frame=0`、`GET /api/replay?session=0&frame=0&strength=0.5`、`GET /api/report`、`GET /api/projection`、`POST /api/enroll`。接口参数越界返回带说明的 JSON 400，缺失资源返回 404。
